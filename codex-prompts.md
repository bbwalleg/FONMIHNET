# Codex prompts for the FONMIHBET promo page

## Prompt 1 — Full landing page build
Create a single-page promotional website for FONMIHBET inspired by the visual style of Fonbet promo pages. Use a dark premium look with deep navy/black background, gold/orange accents, glossy glassy cards, rounded corners, bold typography, and subtle animated gradients. The page should include a top navigation, a hero section with the text “FONMIHBET”, three promotional cards, a center wheel of fortune that spins on click, and a footer with a CTA. Make it feel modern, luxurious, and high-energy. The wheel should be visually striking and placed prominently in the middle of the page.

## Prompt 2 — More premium and branded
Build a polished one-page promo landing page for FONMIHBET that feels like a premium sportsbook campaign site. Use a style similar to Fonbet promo pages, but with a custom identity for FONMIHBET. Include a dramatic hero section, neon-like gold accents, layered shadows, glassmorphism panels, and a large interactive wheel of fortune in the middle. Make the structure feel like a marketing landing page, not a generic app page. Keep the layout responsive and use smooth animations for hover states and the wheel spin.

## Prompt 3 — Focus on the wheel interaction
Create a one-page landing page for FONMIHBET with a centered wheel of fortune as the key focal point. The rest of the page should support it visually with promo sections and a strong hero layout. Use a premium dark theme inspired by Fonbet, with rich gradients, elegant cards, and strong contrast between the background and the highlighted CTA elements. The wheel should spin when the user clicks a button and should display prize labels such as Bonus, Free Bet, Cashback, and VIP.

## Prompt 4 — Copy-ready implementation brief
Build a responsive single-page landing page for FONMIHBET that looks like a polished promotional page inspired by Fonbet. Use a bold dark background, gold accent colors, curved containers, and premium card styling. Include: a sticky-like top bar, a hero section with headline and CTA, a promo card row, a central wheel of fortune section, and a footer. The wheel should be large, circular, and interactive. Use HTML, CSS, and minimal JavaScript only. Add smooth transitions and ensure the page feels premium and game-like.
